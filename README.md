# RoboCup India — React/Vite Website

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints (normally http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```

## Replace images

All current artwork is local SVG placeholder artwork in `public/images/`.
You can replace any SVG with an approved JPG/PNG/WebP photo while keeping the same filename, or update the image path in the relevant component.

## Main files

- `src/App.jsx` — routing
- `src/index.css` — complete responsive design
- `src/components/` — reusable navigation, hero, cards, timeline and FAQ
- `src/pages/` — Home, About, Competitions, Events, Teams, Results, News, Contact
- `public/images/` — local visual assets

## Important before publishing

Replace placeholder event dates, team names, contact information and registration links with official RoboCup India information. Use only logos/photos you have permission to publish.
